Detailed Description

A union to hold SunspecValueFunction for all possible Sunspec point data types.

Each member of the union corresponds to a specific Sunspec data type and holds a SunspecValueFunction which contains a function pointer and a parameter for retrieving the value of that type. The parameter lifetime is managed by the user of the union as no copy is done.
