Sunspec Flatbuffers
A Sunspec library implementation with the models defined using flatbuffers and uses the modbus memory map buffer to store the value of points for efficient memory management.

void setAllValueToModbusBuffer ()
 Sets the values of modbus buffer by calling all the setValueToModbusBuffer function for toplevel SunspecModelWriter for the device. This should be called after assignBuffer to ensure all models and their points are initialized, as it relies on the registerLength_ for all containing sunspec elements being set.
 
void poll ()
 Polls the Modbus client to read the latest data from the device as well as calling setAllValueToModbusBuffer. This method updates the modbus buffer with the latest data from the device. It should be called periodically to ensure the data remains current either in a loop or a timer interrupt callback.
