Detailed Description

template<typename ReturnType>
struct SunspecValueFunction< ReturnType >

A template struct to hold a function pointer and its parameter for retrieving Sunspec point values.

The struct is a functor but with out the call operator being overloaded to an explicit call method. It can take a parameter that has bee ntype erased allowing for the passing any any type of parameter to the function.

ReturnTypeThe return type of the function i.e. the type of the Sunspec point value.
